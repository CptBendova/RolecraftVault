# Contributing

Rolecraft Vault is proprietary source-available software. Public source permits
inspection and auditing, but does not grant permission to publish derivatives.
Read [LICENSE](LICENSE) before contributing.

Bug reports and focused improvement proposals are welcome. Security issues must
use the repository's private vulnerability-reporting form described in
[SECURITY.md](SECURITY.md).

Before proposing code, open an issue describing the behavior, affected Windows
or Android edition, reproduction steps, and data-safety implications. Keep a
change small, preserve `app/app.js`, add a regression check that exercises the
real implementation, and run `npm test`. A pull request does not change the
licence of Rolecraft Vault or grant permission to redistribute it.
